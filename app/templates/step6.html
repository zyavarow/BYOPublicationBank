Anthropic API key

Every question, topic check and library read is billed to an Anthropic account. Enter this organization's own key so that it pays for its own use. The key is stored on the server only: this page never shows it again, and it is never sent to the browser or to anyone but Anthropic.

Create a key in the Anthropic Console (console.anthropic.com → API keys). Set a monthly spending limit there too: it is your safety net, and this app's own limits are in addition to it. Testing a key is free.
