Build the publication bank

Three ways in — use whichever matches what you have. You can mix them: each paper is added once, even if it arrives by more than one route.

PDFs only. Folders are searched including subfolders.
or
Best for a large library: nothing is uploaded, the PDFs are copied straight from that folder.
Reading a PDF takes about a minute on this computer, so a large library takes hours. Keep this window open while it runs. If it is interrupted, adding the same files again picks up where it left off.

Good for

  • The full text, so the AI can read methods, reagents and tables.
  • Papers you have a license or permission for that are not free online.

Watch out for

  • The slowest route: hundreds of PDFs take hours to read.
  • Files can be messy: duplicates, supplements, scans that need text recognition.
  • Titles and IDs have to be recovered from the text of each PDF.
RIS, BibTeX or CSV, up to 25 MB.
In Zotero: select the collection, then File › Export Library, and choose RIS, BibTeX or CSV. In EndNote: File › Export, and save as RIS. EndNote XML is not supported yet.

Good for

  • The organization's own curated list, with clean titles, authors and DOIs.
  • Fast, and duplicates are easy to catch.
  • Each reference is matched to PubMed, so abstracts and open-access full text come with it.

Watch out for

  • An export is usually just citations, with no full text. Papers PubMed does not hold, or that are not open access, stay as citation or abstract only.
  • Some references have no DOI or a different title spelling and will not match.
